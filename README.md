## Featured

### Nuvio — shop, pay, ask the bot
Full-stack SaaS in `full-stack-project/nuvio-saas`. Next.js + MongoDB + Stripe, plus an OpenAI chatbot that actually knows the catalog.

### DIY Hotpot — from menu to checkout
`food ordering website/` — Node, Express, EJS, MongoDB. Roles for customers and clerks, meal kits, and email via Mailgun.

### Face rec — train on *your* face
`MachineLearning/face_rec/` — capture photos, train LBPH, recognize from webcam or a still. No giant model download. Python + OpenCV.

### Linear regression that you can read
Separate repo: [Aashrawat/machine-learning](https://github.com/Aashrawat/machine-learning)

- Gradient descent vs a closed-form fit
- Insurance EDA, cleaning, Pearson + chi-square feature picks
- Ford used-car prices: one-hot vs label encoding (one-hot ~**0.85 R²**, label ~**0.74**)
